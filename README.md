# Quiz CaféByte

Quiz on-line de duas questões sobre **algoritmos, Python e tipos de dados**, usado na aula *Do pensamento lógico ao primeiro código* (Análise e Desenvolvimento de Sistemas · Celso Lisboa).

**Acesse:** https://georgekleinau.github.io/quiz/

## Como funciona

1. O aluno informa o nome (e, se quiser, a matrícula).
2. Responde uma questão por vez e vê na hora o feedback de cada alternativa.
3. No fim, copia o comprovante com o resultado e cola na **Mesa de Trabalho** do Liga Online.

São permitidas duas tentativas. A página não envia nem armazena respostas em servidor: o progresso fica apenas no navegador do aluno.

## Estrutura

- `index.html`: página completa (HTML, CSS e JavaScript em um único arquivo).
